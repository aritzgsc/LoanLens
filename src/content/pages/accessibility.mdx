The site is designed for keyboard navigation, zoom, reduced-motion preferences, and screen readers. Use the Skip to content link to bypass navigation. Form controls have visible labels and calculator results include a text summary. Both charts include a table of selected points and each repayment plan has a textual outcome. Use Print or save as PDF to get a printable comparison.

## Report a barrier

If a page or tool is difficult to use, email [&#123;&#123;CONTACT_EMAIL&#125;&#125;](mailto:%7B%7BCONTACT_EMAIL%7D%7D) with the page name, the action you were trying to complete, and the browser or assistive technology if you are comfortable sharing it. Use fictional figures when describing a calculator issue. We use WCAG 2.2 AA as the design target.
